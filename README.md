# wellbe-mobile

Interactive mobile prototype for WELLBE+, a holistic well-being and mood-tracking web app built around Yale's RULER emotional framework, somatic resets, trend analytics, and burnout prevention.

Key Features
RULER Emotional Check-Ins: 4-quadrant, 16-emotion grid and rapid check-in workflows grounded in Yale's RULER framework, paired with full-grid Instant Check-In expansion and latest-emotion icon cards.
Somatic Resets & Routines: Guided short regulation exercises and recovery routines designed to lower cognitive friction.
Trend Analytics & AI Coach: Longitudinal mood and state patterns surfaced alongside contextual well-being guidance.
Motion & UI Polish: Spring-physics tab transitions, micro-press compression, auto-dismissing toasts, and account settings architecture.

Tech Stack & Design Direction
Frontend: React, TypeScript, Vite, Tailwind CSS
Design System: Minimalist, low-cognitive-load UI with high-contrast dark-mode support and Material 3 cues
Authoring & Deployment: Built with Google AI Studio and deployed on Vercel
